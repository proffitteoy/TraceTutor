## 当前文档之间的关系

可以把核心文档理解成这一条链：

```text
架构设计
  ↓ 规定系统边界
接口与闭环设计
  ↓ 串起跨组件流转
agent设计
  ↓ 定义 Agent 如何调用工具
pgsql设计 + SQLite设计
  ↓ 定义 API 背后的数据资产与状态模型
实现代码
```

也就是说：

- `架构设计` 负责回答“系统分几层”
- `接口与闭环设计` 负责回答“层与层之间怎么接、怎么回写、怎么降级”
- `agent设计` 负责回答“扣子里怎么编排和约束”
- `pgsql设计` 和 `SQLite设计` 负责回答“数据到底怎么存、怎么查、怎么校验”
